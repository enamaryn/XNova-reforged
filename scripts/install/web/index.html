XNOVA REFORGED

Langue de l’installation

Cette langue devient aussi la langue par défaut du jeu, du serveur et des emails.

Installons votre serveur.

La base, la configuration et les services seront préparés ici. Vous configurerez ensuite les emails et votre compte administrateur.

Recopiez le code affiché au lancement de l’installateur sur le serveur.

Votre serveur

L’adresse que les joueurs utiliseront, sans chemin. HTTPS est obligatoire en production.

Base de données

La base, son utilisateur et son mot de passe seront créés sur ce serveur. Les secrets seront générés et enregistrés dans sa configuration.

La base doit déjà exister. L’utilisateur doit pouvoir appliquer les migrations. L’URL reste sur le serveur et n’est pas affichée dans le suivi.

Accès web

Votre proxy peut être sur une autre machine : transmettez le site vers l’IP de ce serveur, port 3000. Les appels API passeront automatiquement par le site.

Le DNS du domaine doit déjà pointer vers ce serveur, accessible sur les ports 80 et 443.

Des services XNova ont été trouvés

Les services seront adaptés à cette installation. Leur configuration précédente sera conservée sur le serveur.

Les anciens services et leurs réglages supplémentaires seront supprimés, puis de nouveaux services seront créés.

Une configuration a déjà été créée. La reprise conserve la base et les secrets ; vous pouvez corriger l’URL externe ou l’email du certificat.
